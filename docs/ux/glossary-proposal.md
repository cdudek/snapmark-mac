# Snapmark glossary proposal

Every term the product shows, where it appears, and the one word proposed for it. Rebuilt by the audit of
2026-09-28 (v0.9.0) from agent 4's term × place table, with places and clashes added from evaluators 1, 2, 3, 5, 6,
7 and 8. Supersedes the proposal of 2026-09-25 (v0.2.0).

**A proposal, not decided.** Nothing here is accepted; every row is a proposal for the owner. One word per meaning
and one meaning per word, everywhere: the menu bar menu, the editor, the session window, the area picker, the
Keyboard Shortcuts window, notifications and dialogs, session.md, the copied prompt, the PDF and the README. The
copied prompt is where the agent learns the words, so its wording is given in the notes.

Finding IDs in the notes refer to the evaluator files of 2026-09-28 (4-nn is agent 4, 1-nn agent 1, and so on).
